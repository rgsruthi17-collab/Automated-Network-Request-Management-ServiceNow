# Empathy Map Canvas

## User: Network Requester

### Says
- I need to submit a network request.
- I want to know whether my request was approved.

### Thinks
- I should provide all required details correctly.
- I need confirmation after submitting the request.

### Does
- Opens the ServiceNow catalog.
- Enters connection, contact, payment and address details.
- Submits the request and checks its status.

### Feels
- Wants a simple and predictable request process.
- Wants confidence that the request is being processed.

## Pain Points
Manual follow-up, unclear approval status and repeated data entry.

## Gains
Centralized request information, automated notification, approval tracking and faster administrative processing.
