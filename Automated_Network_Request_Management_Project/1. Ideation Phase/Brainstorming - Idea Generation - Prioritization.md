# Brainstorming – Idea Generation – Prioritization

## Project
Automated Network Request Management in ServiceNow

## Ideas Considered
1. Manual network request tracking through email.
2. ServiceNow catalog-based network request management.
3. Automated approval and database record creation.
4. Automated email notification and status updates.

## Selected Idea
A ServiceNow catalog item that captures network requests, creates a database record, sends notification, requests approval, and updates the record after approval.

## Prioritization
| Idea | Value | Automation | Feasibility | Priority |
|---|---|---|---|---|
| Manual email tracking | Low | Low | High | Low |
| Catalog-based request | High | Medium | High | High |
| Approval automation | High | High | High | High |
| Automated notifications | Medium | High | High | High |

## Final Decision
Combine catalog submission, record creation, email notification, approval and update automation into one ServiceNow workflow.
