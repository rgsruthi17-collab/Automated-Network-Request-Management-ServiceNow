# 1. Ideation Phase

## Problem Identification

Network connection requests are often handled through manual communication and separate records. This can make request tracking, approval, notification, and status updates difficult.

## Proposed Idea

Build an automated Network Request Management solution in ServiceNow using Service Catalog and Flow Designer.

## Objectives

- Provide a structured form for network requests.
- Capture requester and connection details consistently.
- Show the Existing ID field only when an existing connection is selected.
- Store submitted request information in a centralized table.
- Automate notifications and approval handling.
- Update the request record after an approval decision.

## Expected Outcome

A simple and traceable workflow from request submission to approval and database update.

## Idea Prioritization

The proposed solution was selected because it combines practical ServiceNow features and directly addresses manual network-request processing.
