# Final Project Documentation

## Title
Automated Network Request Management in ServiceNow

## Summary
The project demonstrates an end-to-end ServiceNow network request workflow. Users submit a structured catalog request; the platform retrieves variables, creates a database record, sends a notification, obtains approval and updates the record on the approved path.

## Key Configuration
- Catalog: Service Catalog
- Category: Network
- Catalog Item: Network Request
- Variable Set: Network Request User Details
- UI Policy: Existing ID visibility control
- Automation: Flow Designer
- Storage: Custom Database Table

## Validation
The project was validated through request submission, approval and Flow Designer execution.
