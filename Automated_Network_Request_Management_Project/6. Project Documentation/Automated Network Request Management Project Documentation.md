# Automated Network Request Management Project Documentation

## Project Overview
Automated Network Request Management in ServiceNow is a Service Catalog and Flow Designer solution for structured network request processing.

## Implemented Modules
- Network Request Catalog Item
- Network Request User Details Variable Set
- New/Existing connection choice
- Existing ID UI Policy
- Custom Database Table
- Flow Designer automation
- Email notification
- Approval process
- Approved-path record update

## Automation
Service Catalog → Get Catalog Variables → Create Record → Send Email → Ask for Approval → If Request is Approved → Update Record.

## Result
The implemented workflow was tested with a submitted request, an approved database record and a completed Flow Designer test execution.
