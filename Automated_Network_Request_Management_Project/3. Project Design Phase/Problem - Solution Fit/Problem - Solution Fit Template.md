# Problem – Solution Fit

## Problem
Network requests need consistent data capture, approval tracking and communication.

## Solution
A ServiceNow Catalog Item collects request details and Flow Designer automates record creation, notification, approval and update.

## Fit
| Need | Project Feature |
|---|---|
| Structured input | Network Request Catalog Item |
| Conditional information | UI Policy |
| Reusable user data | Variable Set |
| Central record | Custom Database Table |
| Notification | Send Email |
| Approval | Ask for Approval |
| Post-approval update | Update Record |
