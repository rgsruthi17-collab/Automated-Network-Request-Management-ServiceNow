# Existing and Proposed System

## Existing System
A manual approach may rely on separate communication, manual data entry and follow-up for approval and processing.

## Proposed System
The proposed ServiceNow solution centralizes the request in a Catalog Item and automates the main workflow using Flow Designer.

## Improvement
The proposed process provides consistent input, a database record, notification, approval tracking and an update after approval.
