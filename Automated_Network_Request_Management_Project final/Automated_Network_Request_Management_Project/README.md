# Automated Network Request Management in ServiceNow

The project standardizes network-service request submission, validation, approval, notification, and record updates using ServiceNow Service Catalog, catalog variables, a reusable variable set, a Catalog UI Policy, a custom table, and Flow Designer.

## Project phases
1. Ideation Phase
2. Requirement Analysis
3. Project Design Phase
4. Project Planning Phase
5. Project Development Phase
6. Project Documentation

## Automation flow
`Service Catalog Request → Get Catalog Variables → Create Record → Send Email → Ask for Approval → Check Approval → Update Record`
