# Project Documentation

This folder contains the complete six-phase documentation set for **Automated Network Request Management in ServiceNow**.

## Contents
- 1. Ideation Phase — problem discovery, brainstorming, and user empathy
- 2. Requirement Analysis — functional/non-functional requirements, user stories, data flow, and technology stack
- 3. Project Design Phase — problem-solution fit, proposed solution, and architecture
- 4. Project Planning Phase — phases, activities, dependencies, and deliverables
- 5. Project Development Phase — functional, performance, and user acceptance testing
- 6. Project Documentation — consolidated project report and evidence checklist

The documentation describes the ServiceNow implementation using Service Catalog, catalog variables, a reusable variable set, Catalog UI Policy, a custom table, and Flow Designer.
