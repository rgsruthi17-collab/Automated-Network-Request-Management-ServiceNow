# Automated Network Request Management Project Documentation

## Abstract
This project uses ServiceNow to standardize network-service request intake and automate record creation, notification, approval, and status updates.

## Objectives
- Provide a structured Service Catalog request form.
- Reuse requester details and conditionally show relevant fields.
- Store request information in a custom table.
- Coordinate processing through Flow Designer.
- Record approval outcomes.

## Modules
1. Request form and variables
2. Reusable user-details variable set
3. Catalog UI Policy
4. Custom request table
5. Flow Designer automation
6. Notifications and approvals
7. Testing and documentation

## Conclusion
The solution demonstrates a platform-native way to organize request data and automate key approval steps. Maintainability depends on clear mappings, appropriate roles, and repeatable tests.
