# Project Evidence Checklist

Use genuine screenshots from the configured ServiceNow instance. Do not use placeholder images as proof.

- [ ] Service Catalog item in the portal
- [ ] Catalog form with required variables
- [ ] Existing ID field visible when applicable
- [ ] Existing ID field hidden when not applicable
- [ ] Submitted request / Requested Item
- [ ] Custom table record with mapped values
- [ ] Flow Designer flow overview
- [ ] Successful flow execution details
- [ ] Notification step or received notification
- [ ] Approval record with approved outcome
- [ ] Custom record updated to Approved
- [ ] Rejection test and updated Rejected status

For each screenshot, add a caption, test case ID, and the result it demonstrates. Remove personal or confidential information before publishing.
