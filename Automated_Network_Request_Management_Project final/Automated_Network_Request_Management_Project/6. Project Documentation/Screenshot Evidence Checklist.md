# Screenshot Evidence Checklist

Capture genuine screenshots from the ServiceNow instance. Remove or mask personal, customer, and environment-sensitive information before sharing publicly.

## Ideation and requirements
- [ ] Problem statement and scope
- [ ] Brainstorming/prioritization
- [ ] Requirements and user stories

## Service Catalog configuration
- [ ] Network Request catalog item configuration
- [ ] Catalog item as seen in Service Portal
- [ ] Catalog variables and mandatory settings
- [ ] Reusable user-details variable set
- [ ] Catalog UI Policy and condition for Existing ID
- [ ] Form with Existing ID visible
- [ ] Form with Existing ID hidden

## Data and automation
- [ ] Custom table definition and fields
- [ ] Flow Designer overall flow
- [ ] Get Catalog Variables step and mappings
- [ ] Create Record step and field mappings
- [ ] Email notification step
- [ ] Ask for Approval and approval configuration
- [ ] Approval decision check
- [ ] Update Record step

## End-to-end validation
- [ ] Submitted Request and Requested Item
- [ ] Approval record and completed decision
- [ ] Created custom-table record
- [ ] Final approval status on the record
- [ ] Successful Flow Designer execution details

## Evidence notes
For each screenshot, record the date, test scenario, expected result, actual result, and any relevant execution identifier. Use real screenshots only; do not replace evidence with mockups or generated images.
