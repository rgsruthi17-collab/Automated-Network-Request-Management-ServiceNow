# Brainstorming – Idea Generation – Prioritization

## Challenge
Network-service requests can require repeated manual data collection, follow-ups, approval tracking, and updates across separate records.

## Ideas considered
- A Service Catalog item to standardize request submission.
- Conditional fields to show only relevant information.
- A reusable user-details variable set.
- A custom table to store request data and approval status.
- Flow Designer to create records, notify stakeholders, request approval, and update status.

## Prioritization
| Idea | User value | Feasibility | Priority |
|---|---|---|---|
| Standard catalog form | High | High | Must have |
| Reusable user details | High | High | Must have |
| Automated record creation | High | High | Must have |
| Approval workflow | High | High | Must have |
| Email notification | Medium | High | Should have |
| Advanced analytics | Medium | Medium | Future |

## Selected concept
Build a centralized ServiceNow workflow that makes network requests consistent, traceable, and easier to process.
